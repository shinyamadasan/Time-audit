Recommendation: A for the first production slice

It most directly serves “I already finished this” with the least competing UI and more room for task text. B is stronger if finding specific tasks dominates daily use. C is useful for dedicated cleanup, but selection does not make one-tap completion faster and its batch protocol is the most complex.

This is a recommendation, not an approved or automatically selected design. The historical completion write and safe Undo do not exist merely because these mocks demonstrate them.
